Nave Payment Provider

Official integration with Nave (Galicia / Naranja X) for online checkouts and payment links.

Nave Payment Provider enables secure and seamless online credit/debit card checkouts and payment links inside Odoo 18. Developed with native multi-company architecture and modern Odoo standards.

Key Features

Redirect Checkout

Provides a smooth checkout redirect experience for your customers, ensuring secure external payment handling through the official Nave platform.

Payment Links

Generate custom payment links directly from customer invoices or sale orders with a single click. Links are sent via email for fast payments.

Asynchronous Webhooks

Real-time transaction status updates and automatic reconciliation via S2S secure callbacks, protecting your workflow against webhook spoofing.

Technical Excellence

  • Token Caching: Optimizes performance by securely caching Auth0 M2M access tokens, minimizing API requests.
  • Multi-Company Ready: Fully isolated payment configurations and credentials per company.
  • Refunds & Cancellations: Issue full or partial refunds directly from Odoo payment transactions.
